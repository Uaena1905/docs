### Create order

<div className="api-table-wrap">

| Request URL | Method | Authorization |
| --- | --- | --- |
| https://{"{test/production domain}"}/payout/applypayout.php | POST | Merchant submits payout information to notify UD and obtain a payment link |

</div>

### Request parameters

<div className="api-table-wrap">

| Parameter | Required | Type | Max length | Description |
| --- | --- | --- | --- | --- |
| appId | Yes | String | 32 | appId from the UD console |
| body | No | String | 128 | Remark |
| merchantOrder | Yes | String | 32 | Merchant order ID (must be unique) |
| price | Yes | String | 10 | Amount in major currency units |
| payCallbackUrl | Yes | String | 256 | Merchant payment callback URL |
| name | Yes | String | 256 | Account name; English supported |
| currencyCode | Yes | String | 12 | Payment currency (for example, KRW) |
| email | Yes | String | 64 | Email address |
| phone | Yes | String | 64 | Phone number |
| userId | Yes | String | 32 | Merchant user ID |
| ctime | Yes | int | 13 | Timestamp (seconds) |
| sign | Yes | String | 128 | Signature rules: [Config and signature](/en/config) |
| payChannel | Yes | String | 32 | Payment method code |
| accountNo | Yes | String | 64 | Card number / IBAN |
| firstName | No | String | 64 | Customer English first name |
| arfirstName | No | String | 64 | Customer Arabic first name |

</div>

### Response

```json
{
    "status": 1,
    "payOrder": oytxad8832848  UD order ID,
    "msg": "代付已经申请"
}
```

### Response fields

<div className="api-table-wrap">

| Field | Type | Max length | Description |
| --- | --- | --- | --- |
| status | int | 11 | `1` means authorization succeeded, `0` means failure |
| payOrder | String | 64 | UD order ID |

</div>
