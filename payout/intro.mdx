## 一、代付产品是什么（客户视角）

UgameDeal 代付（Payout / 资金下发）：商户通过 UD API，从平台商户资金账户向指定收款人（玩家、KOL、供应商等）的本地银行卡或电子钱包直接打款，无需人工操作网银。

- **资金方向**：商户 UD 账户 → 收款人银行卡 / 本地钱包
- **支持对象**：对私（个人玩家/KOL）｜ 对公（供应商/渠道）
- **覆盖区域**：多国本地银行 + 电子钱包（如东南亚/南亚主流通道）
- **接入方式**：HTTPS + IP 白名单 + 参数签名（MD5 / RSA_SHA256）
- **模式**：单笔代付 ＋ 批量代付 ＋ 异步回调通知 ＋ 订单查询

## 二、代付典型应用场景（游戏/出海业务向）

| 场景 | 说明 | 特点 |
| --- | --- | --- |
| 玩家余额提现 / 退款原路打款 | 玩家在游戏 Web Shop 充值返利、余额提现到本地银行卡/钱包 | 高频、小额、重视到账时效 |
| KOL / 主播 / 推广员佣金发放 | 按周/月向网红、联盟客发放推广分成 | 批量代付、需留打款凭证 |
| 赛事奖金 / 活动奖励下发 | 电竞赛事冠军队、签到抽奖现金奖励直发 | 一次性批量、备注清晰 |
| 供应商 / 渠道结算付款 | 向下游本地发行商或美术外包付结算款 | 对公代付、金额大、T+N |
| 客服补偿 / 误扣款退还 | 玩家投诉核实后直接补偿到其账户 | 需关联订单号、可追溯 |

## 三、如何使用代付功能

- **开通流程**：联系 UgameDeal 商务团队申请开通代付权限
- **接入方式**：通过 API 接口对接，支持单笔代付和批量代付
- **安全保障**：采用 HTTPS 加密传输 + IP 白名单 + 参数签名验证
- **到账时效**：根据不同渠道和地区，一般为实时到 T+1 个工作日
- **费用说明**：按笔收取手续费或按比例收费，具体费率请咨询商务团队
